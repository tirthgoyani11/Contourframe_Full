# Code of conduct

Treat other participants with respect. Give feedback about the work, respect privacy, and give people room to learn and disagree.

Harassment, discrimination, threats, sexualized remarks directed at others, and sharing private information without consent are unacceptable in project discussions, reviews and events.

Report incidents privately to a repository maintainer using the contact details on their GitHub profile. Include relevant links and any immediate concerns. Maintainers should limit access to reports, review the context and explain their decision to the people involved where appropriate.

Maintainers may remove content, issue warnings or restrict participation in response to violations.
