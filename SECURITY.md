# Security policy

Report vulnerabilities privately through GitHub’s **Security → Report a vulnerability** once private reporting is enabled. If that control is unavailable, contact a maintainer privately through their profile.

Include the affected version or commit, the relevant component, the impact and enough detail for a maintainer to verify the report. Keep credentials and personal data out of reports. Coordinate disclosure with the maintainers.

Contourframe Studio is designed for local use. Keep the server bound to `127.0.0.1`.
